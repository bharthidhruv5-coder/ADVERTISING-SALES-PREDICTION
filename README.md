# 📊 Advertising Sales Prediction

### Machine Learning Project | Python | Data Science

## 📌 Project Overview

Advertising Sales Prediction is a Machine Learning project that predicts product sales based on advertising expenditure across different marketing channels.

The project analyzes the relationship between advertising budgets and sales to help businesses understand how advertising investments can influence sales performance.

## 🎯 Objectives

- Predict product sales using advertising data.
- Analyze the impact of different advertising channels.
- Explore relationships between advertising expenditure and sales.
- Build and evaluate a Machine Learning regression model.
- Improve business decision-making through data analysis.

## 📂 Dataset Description

The project uses advertising data containing the following features:

| Feature | Description |
|---|---|
| TV | Advertising expenditure on TV |
| Radio | Advertising expenditure on Radio |
| Newspaper | Advertising expenditure on Newspaper |
| Sales | Product sales (Target Variable) |
